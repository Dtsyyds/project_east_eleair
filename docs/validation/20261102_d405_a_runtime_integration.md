## 四项操作

以下实时操作是交付给操作者的后续操作说明，本轮没有自动执行硬件启动。已运行的旧系统不会因修改文件自动变成A；不要为了本轮验证重启相机。

### 1. 本机离线测试

在项目根目录执行，输出目录必须尚不存在：

```bash
cd /media/mcap_data/project_east_eleair_refactor
bash tools/vision/test_d405_a_offline.sh \
  .runtime/s100p/validation/d405_a_offline_rerun
```

此脚本只读既有样本/录像，使用隔离ROS域187和localhost，启动测试发布器、被动算法节点及回放录制器；不启动相机或底盘。若执行环境限制本地套接字，需允许本机测试网络权限。

### 2. 仅实时预览

在后续由操作者安排的正常启动时执行：

```bash
cd /media/mcap_data/project_east_eleair_refactor
bash system_websocket/run_d405.sh
```

这是正式硬件入口，会在正常启动时启动D405；本轮未执行。打开终端给出的网页地址（本机通常 `http://127.0.0.1:8080`），进入“实时巡检”，点击 **启动视觉巡迹**。界面应显示“A原评分 · RGB”，结果详情可核对模型SHA。**不点击“一键启动采集”就不录像。**

若已有系统运行，直接查看现有页面，不重复启动另一套设备进程；当前进程是否已使用A，以实际配置/模型标识为准。旧算法回退在后续正常启动时使用 `bash system_websocket/run_d405.sh --legacy`。

预览会话目录：`/media/mcap_data/vision_experiments/VISION-*/`，默认仅配置、会话和进程日志；显式“保存实验样本”另写样本。A为彩色逐帧模式，单帧样本不承诺同步深度；连续录制仍保留专用配置列出的原彩色、深度、红外及标定流。

### 3. 手动开始录像

网页进入 **采集任务** → 填写任务信息 → **执行预检** → 等待“就绪” → **一键启动采集**。

确认状态进入“采集中”，记录界面显示的 `WS-*` 批次。正式手动录像输出：

`/media/mcap_data/runs/WS-*/bag/*.mcap`

MCAP保存带原始时间戳的图像及配置指定的话题，不是浏览器JPEG录像，也不默认导出MP4。

### 4. 停止并保存

点击 **一键停止**，等待关闭/校验完成并显示保存目录；检查 `run.json` 的 `complete=true` 和MCAP元数据。停止录像不停止巡迹；需要结束巡迹时再点 **停止视觉巡迹**。不要以刷新/关闭网页替代停止保存操作。
