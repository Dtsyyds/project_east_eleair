# 雷达到相机外参表示总结

## 1. 坐标系定义

设：

- \(L\)：LiDAR（激光雷达）坐标系
- \(C\)：Camera（相机）坐标系
- \({}^{L}\mathbf{p}\)：点在雷达坐标系中的坐标
- \({}^{C}\mathbf{p}\)：同一个点在相机坐标系中的坐标

如果定义外参为“雷达到相机”的变换，则记为：

\[
\boxed{{}^{C}T_{L}}
\]

它表示：

\[
\boxed{L \rightarrow C}
\]

即把雷达坐标系中的点转换到相机坐标系中。

---

## 2. 最基本的坐标变换公式

雷达到相机的外参满足：

\[
\boxed{
{}^{C}\mathbf{p}
=
{}^{C}R_{L}\,{}^{L}\mathbf{p}
+
{}^{C}\mathbf{t}_{L}
}
\]

其中：

\[
{}^{C}R_{L}\in \mathbb{R}^{3\times3}
\]

表示雷达坐标系相对于相机坐标系的旋转关系；

\[
{}^{C}\mathbf{t}_{L}\in \mathbb{R}^{3\times1}
\]

表示雷达坐标系原点在相机坐标系中的坐标。

因此，外参由两部分组成：

\[
\boxed{\text{Extrinsic} = (R,t)}
\]

---

## 3. 齐次变换矩阵表示

将旋转和平移写成 \(4\times4\) 齐次变换矩阵：

\[
\boxed{
{}^{C}T_{L}
=
\begin{bmatrix}
{}^{C}R_{L} & {}^{C}\mathbf{t}_{L}\\
0\quad0\quad0 & 1
\end{bmatrix}
}
\]

如果使用齐次坐标：

\[
{}^{L}\tilde{\mathbf p}
=
\begin{bmatrix}
x_L\\
y_L\\
z_L\\
1
\end{bmatrix}
\]

则：

\[
\boxed{
{}^{C}\tilde{\mathbf p}
=
{}^{C}T_{L}
{}^{L}\tilde{\mathbf p}
}
\]

这也是工程中最常用的外参表示形式。

---

## 4. 记号的推荐理解

推荐统一采用：

\[
\boxed{{}^{target}T_{source}}
\]

即：

\[
\boxed{
{}^{target}\mathbf p
=
{}^{target}T_{source}
{}^{source}\mathbf p
}
\]

因此：

\[
{}^{C}T_{L}
\]

表示：

\[
\boxed{\text{LiDAR} \rightarrow \text{Camera}}
\]

而：

\[
{}^{L}T_{C}
\]

表示：

\[
\boxed{\text{Camera} \rightarrow \text{LiDAR}}
\]

这种记法比 `Tcl`、`Tlc` 更不容易产生歧义。

---

## 5. 平移向量的真实含义

对于：

\[
{}^{C}\mathbf p
=
{}^{C}R_{L}{}^{L}\mathbf p
+
{}^{C}\mathbf t_{L}
\]

令雷达坐标系中的点为雷达原点：

\[
{}^{L}\mathbf p=
\begin{bmatrix}
0\\0\\0
\end{bmatrix}
\]

则：

\[
{}^{C}\mathbf p
=
{}^{C}\mathbf t_{L}
\]

因此：

\[
\boxed{{}^{C}\mathbf t_{L}}
\]

表示：

> 雷达坐标系原点在相机坐标系中的坐标。

所以不能简单地把 \(t\) 理解成“从雷达到相机的物理位移向量”。

---

## 6. 相机到雷达外参

雷达到相机外参与相机到雷达外参互为逆变换：

\[
\boxed{
{}^{L}T_{C}
=
\left({}^{C}T_{L}\right)^{-1}
}
\]

若：

\[
{}^{C}T_{L}
=
\begin{bmatrix}
R&t\\
0&1
\end{bmatrix}
\]

则：

\[
\boxed{
{}^{L}T_{C}
=
\begin{bmatrix}
R^{T}&-R^{T}t\\
0&1
\end{bmatrix}
}
\]

因此：

\[
\boxed{
{}^{L}R_{C}
=
\left({}^{C}R_{L}\right)^T
}
\]

以及：

\[
\boxed{
{}^{L}t_{C}
=
-
\left({}^{C}R_{L}\right)^T
{}^{C}t_{L}
}
\]

---

## 7. 雷达点投影到相机图像

在雷达-相机融合中，经常需要把 LiDAR 点云投影到相机图像。

整个变换过程为：

\[
\boxed{
\text{LiDAR}
\rightarrow
\text{Camera}
\rightarrow
\text{Image}
}
\]

首先进行外参变换：

\[
{}^{C}\mathbf p
=
{}^{C}R_{L}{}^{L}\mathbf p
+
{}^{C}\mathbf t_{L}
\]

设：

\[
{}^{C}\mathbf p=
\begin{bmatrix}
X_C\\
Y_C\\
Z_C
\end{bmatrix}
\]

相机内参矩阵：

\[
K=
\begin{bmatrix}
f_x&0&c_x\\
0&f_y&c_y\\
0&0&1
\end{bmatrix}
\]

则图像投影关系为：

\[
\boxed{
s
\begin{bmatrix}
u\\
v\\
1
\end{bmatrix}
=
K
\begin{bmatrix}
X_C\\
Y_C\\
Z_C
\end{bmatrix}
}
\]

将外参代入可得：

\[
\boxed{
s
\begin{bmatrix}
u\\
v\\
1
\end{bmatrix}
=
K
\left(
{}^{C}R_{L}{}^{L}\mathbf p
+
{}^{C}\mathbf t_{L}
\right)
}
\]

因此，在点云投影任务中，使用“雷达到相机”的外参最为直接。

---

## 8. 工程中常见的变量名

常见写法包括：

```text
Rcl
Tcl
Pcl
R_lidar_to_camera
T_lidar_to_camera
extrinsic
extrinsic_matrix
```

例如：

```yaml
Rcl: [...]
Pcl: [...]
```

如果代码中使用：

\[
P_C = R_{cl}P_L + P_{cl}
\]

那么：

\[
R_{cl} = {}^{C}R_{L}
\]

\[
P_{cl} = {}^{C}t_{L}
\]

即表示：

\[
\boxed{\text{LiDAR} \rightarrow \text{Camera}}
\]

需要注意：

> 仅根据变量名 `Rcl` 或 `Tcl` 并不能百分之百确定变换方向，必须结合程序中的实际公式判断。

---

## 9. 判断外参方向的最可靠方法

如果程序中出现：

\[
P_C = RP_L+t
\]

那么：

\[
\boxed{R,t:\ L\rightarrow C}
\]

如果程序中出现：

\[
P_L = RP_C+t
\]

那么：

\[
\boxed{R,t:\ C\rightarrow L}
\]

因此，判断外参方向时应优先查看：

1. 输入点属于哪个坐标系；
2. 输出点属于哪个坐标系；
3. 变换公式是如何写的；
4. 再结合变量名进行判断。

---

## 10. 最终推荐写法

在论文、技术文档和代码注释中，推荐统一定义：

\[
\boxed{
{}^{C}\mathbf p
=
{}^{C}R_{L}\,{}^{L}\mathbf p
+
{}^{C}\mathbf t_{L}
}
\]

以及：

\[
\boxed{
{}^{C}T_{L}
=
\begin{bmatrix}
{}^{C}R_{L}&{}^{C}\mathbf t_{L}\\
0&1
\end{bmatrix}
}
\]

并明确说明：

> \({}^{C}T_{L}\) 表示从 LiDAR 坐标系到 Camera 坐标系的刚体变换，即 LiDAR-to-Camera 外参。

---

## 11. 一句话总结

\[
\boxed{
{}^{C}T_{L}:\quad
{}^{C}\mathbf p
=
{}^{C}T_{L}\,{}^{L}\mathbf p
}
\]

其中上标表示目标坐标系，下标表示源坐标系，因此：

\[
\boxed{{}^{C}T_{L}=\text{雷达到相机的外参}}
\]
