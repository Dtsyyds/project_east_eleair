  你按 Ctrl-C 中断的是停止后的离线校验，所以当前仍显示：

  {
    "complete": false,
    "finalized": false,
    "validation": "pending"
  }

  无参数停止已经支持。以后直接执行：

  scripts/stop_vehicle_collection.sh

  规则是：

  1. 优先使用当前 shell 中的 FIELD_RUN_ID。
  2. 没有该变量时，自动查找唯一仍在运行的采集 run。
  3. 如果同时存在多个活跃 run，会拒绝猜测并要求明确指定。
  4. 没有活跃 run 时也会安全退出。

  如果只想立即停止录制、不等待数分钟的离线 MCAP 校验：

  FIELD_SKIP_FINALIZE=1 scripts/stop_vehicle_collection.sh

  之后可以单独执行校验：

  python3 scripts/finalize_vehicle_collection.py \
    /media/mcap_data/runs/FIELD-VEHICLE-20260922_232714

  这个 run 之前受到旧数据回放污染，不建议继续花时间作为正式 run 验收。新采集正常
  启动后，结束时直接运行：

  scripts/stop_vehicle_collection.sh

  现在停止过程也会先明确显示：

  recording processes stopped
  MCAP writers sealed; starting offline validation

  看到第一行时，实际录制就已经停止；后面只是离线校验。
